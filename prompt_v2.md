# Build Prompt — OmniWrite Pro: 100% Offline AI Writing & Productivity Suite

Build a polished, professional desktop application prototype called **OmniWrite Pro** — a **100% offline, privacy-first AI writing, paraphrasing, AI detection/humanizing, and LaTeX studio suite**.

The application must feature a modern **Tile-Based Dashboard Hub** inspired by suite applications (like Canva / Adobe Creative Cloud / Notion Workspace), where users select dedicated tools from interactive tiles and launch directly into focused workspaces.

---

## 1. CRITICAL REQUIREMENT — 100% OFFLINE & PRIVACY FIRST

* The application must work **completely offline with zero internet connection**.
* Do NOT send text or user data to external cloud APIs (No OpenAI, Claude, Gemini, QuillBot, or Grammarly APIs).
* All analysis, paraphrasing, AI detection, humanizing, and LaTeX compilation must execute locally on the user's machine.
* For AI features, support local models via **Ollama** (`http://127.0.0.1:11434`) or local rule/heuristic fallback engines.
* The application must function gracefully even if no local LLM service is installed.

## 3. CORE MODULE SPECIFICATIONS

### Module A: 🔄 Offline QuillBot-Style Paraphraser
Build a dedicated paraphrasing tool featuring:
* **Paraphrase Modes**:
  - **Standard**: Balanced rephrasing maintaining original intent.
  - **Fluency**: Enhances grammar and sentence flow.
  - **Formal**: Professional, business, or academic tone.
  - **Academic**: Advanced vocabulary and scholarly phrasing.
  - **Creative**: Imaginative rephrasing with varied vocabulary.
  - **Expand**: Elaborates sentences with extra detail.
  - **Shorten**: Concise rephrasing removing fluff.
* **Synonym Density Slider**: Adjust replacement frequency (`Low` | `Medium` | `High`).
* **Freeze Words List**: Allow users to lock specific terms/jargon so they are never changed during paraphrasing.
* **Variant Comparison**: Show 3 alternative sentence options for any selected output sentence.

### Module B: 🛡️ Offline AI Detector & Text Humanizer (AI Remover)
Build an offline AI content inspector and text humanizer:
* **AI Content Detector**:
  - Computes a local **AI Probability Score** (0–100%) based on text perplexity, burstiness, sentence variance, and vocabulary repetition.
  - Highlights specific sentences likely generated by AI in yellow/orange.
* **AI Text Humanizer (AI Remover)**:
  - Rewrites text locally to bypass AI detectors by varying sentence length, breaking uniform syntax patterns, introducing natural transitions, and increasing perplexity.
  - One-click **"Humanize Text"** action that updates the document and lowers the AI score.

### Module C: 📐 Offline LaTeX Studio & Live Math Renderer
Build a dedicated LaTeX workspace:
* **Side-by-Side View**: Left LaTeX code editor + Right live rendered math preview.
* **Live KaTeX/MathJax Integration**: Instant rendering for inline formulas (`$e^{i\pi} + 1 = 0$`) and block equations (`\sum`, `\int`, matrices, fractions).
* **Symbol Palette**: Quick-click toolbar for math symbols, Greek letters, matrices, and operators.
* **Export Options**: Export rendered document to **PDF**, **HTML**, or **SVG/PNG** image.

### Module D: ✍️ WriteWise Assistant & 📊 ATS Resume Optimizer
* Integrate the full WriteWise grammar engine (Grammarly-style inline wavy underlines, floating suggestion popups, Flesch readability, tone detector, Writing Score).
* Integrate the ATS Resume Score Checker (Action verbs, metrics quantification, cliche removal, section header analysis).

## 4. TECH STACK & ARCHITECTURE

* **Desktop Stack**: Electron + React + TypeScript + Vite + Tailwind CSS
* **Rich Text Editor**: TipTap / ProseMirror
* **Math Renderer**: KaTeX (100% offline rendering)
* **Icons & Styling**: Lucide React, Tailwind CSS, dark mode support
* **Local Storage**: IndexedDB / LocalStorage for multi-tool documents
* **Local LLM**: Ollama (`http://127.0.0.1:11434`) for local AI rewriting & paraphrasing with rule-based fallback
